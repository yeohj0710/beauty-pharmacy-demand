# 제품 수요 대시보드

제품별 온라인 관심 신호를 수집하고 원본 근거와 함께 검토하는 대시보드입니다.

## 데이터 범위

- 등록 제품명과 수요 개체
- YouTube, Instagram, TikTok, 네이버, Google의 공개 검색 결과
- 조사자가 직접 확인한 콘텐츠 지표와 원본 URL
- 내부 매출·판매량·순이익·이익률은 사용하지 않습니다.

## 실행

```bash
npm install
npm run dev
```
