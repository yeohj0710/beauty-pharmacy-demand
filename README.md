# Demand Radar

약국 실판매 데이터와 온라인 관심 신호를 비교해 제품 수요를 검증하는 대시보드입니다.

## 현재 데이터

- 성수 퓨어약국 2026년 6월 판매 데이터 50개 제품
- 판매수량, 매출, 순이익, 이익률, 90일 월평균 비교
- 온라인 신호는 수집 파이프라인 연결 전 검증용 샘플이며 실제 지표가 아닙니다.

## 실행

```bash
npm install
npm run dev
```
